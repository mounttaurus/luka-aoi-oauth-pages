プライバシーポリシー

Luka and Aoi Uploader（以下「本ツール」）は、運営者本人が自分の YouTube チャンネルへ動画を上げるための個人用ツールです。

利用する権限

Google の認可で、YouTube のアップロード権限（youtube.upload）だけを使います。動画のアップロード以外（チャンネルの設定変更、動画の削除、他人のデータの閲覧など）には使いません。

データの扱い

  • 本ツールは、個人情報を収集しません。
  • 認可で得た情報（トークン）は、運営者本人のパソコンの中だけに保存します。外部のサーバーには送りません。
  • データを第三者へ提供・販売・共有しません。
  • 広告や解析のための仕組みは使いません。

Google API の利用

本ツールによる Google API から得た情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

Privacy Policy (summary)

This is a personal tool used only by its owner. It requests only the YouTube upload scope, collects no personal data, stores its tokens only on the owner's own computer, and does not share data with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
